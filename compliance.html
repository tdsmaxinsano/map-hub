Drop BOTH files below. The two reports join on Last name + First name + DOB + Referral date. Patient/episode/agency data is refreshed every import; your edits to category, sync status, and notes are preserved across re-imports.
📖 How to export these two reports from TherapyBoss

① Active Services .csv

  1. TB → Reports → Services → Active services
  2. Select all fields → Download as CSV.

② Patient List .xlsx

  1. In TherapyBoss, click the Referrals tab in the top nav.
  2. Click the Active sub-tab (between Pending and Other providers). The Status: Active filter pill should now show.
  3. Click the small green Excel icon on the left side (just left of the Status: Active filter pill) → the export downloads as a .xlsx.

Drop the Active Services .csv into ① and the Patient List .xlsx into ② below. The Import button enables once both files parse and a non-zero join count is shown.

📅 Import Scheduled Appointments
Phase-2 enrichment — adds eval-scheduling info to rows already imported via the base import. Matches on Patient ID + Service. Rows in your file that don't match an existing evaluation item are skipped (no phantom rows added).
📖 How to export Scheduled Appointments from TherapyBoss
  1. TB → Reports → Clinicians → Scheduled appointments
  2. Set the date range to cover at least past 30 days through next 30 days (gives us missed-eval detection + upcoming eval visibility)
  3. Select all fields → Download as CSV
  4. Drop the .csv below

👤 Import Patient Visits
Phase-3 enrichment — verifies which evals actually got done and were synced. Matches on Patient ID + Service. Auto-updates sync status: eval visit + note completed → 🟢 synced. Eval visit + note pending → 🟡 not synced.
📖 How to export Patient Visits from TherapyBoss
  1. TB → Reports → Clinicians → Patient visits
  2. Set the date range to cover at least the last 60 days (catches all initial evals + recent re-evals for current episodes)
  3. Select all fields → Download as CSV
  4. Drop the .csv below
